# بوت المحاسبة عبر تيليغرام

بوت بسيط ومجاني بالكامل لتسجيل المبيعات والمصاريف والديون عبر تيليغرام.

## المرحلة الحالية
✅ تسجيل مبيعات ومصاريف بجملة حرة بسيطة (كلمات مفتاحية)
✅ تسجيل وتتبع الديون (لك / عليك)
✅ تقارير يومية وشهرية
⏳ لاحقًا: تحويل الرسائل الصوتية لأوامر تلقائية بالذكاء الاصطناعي
⏳ لاحقًا: موقع ويب لعرض التقارير بشكل مرئي

## خطوات التشغيل

### 1. إنشاء البوت والحصول على التوكن
1. افتح تيليغرام وابحث عن `@BotFather`
2. أرسل له `/newbot` واتبع التعليمات (اسم البوت + username ينتهي بـ `bot`)
3. رح يعطيك توكن شكله متل: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`
4. احتفظ فيه، بس ما تشاركه مع حدا

### 2. تثبيت المتطلبات
```bash
pip install -r requirements.txt --break-system-packages
```
(أو استخدم بيئة افتراضية `venv` إذا حابب)

### 3. تشغيل البوت
**الطريقة الأولى - متغير بيئة (أفضل وأأمن):**
```bash
export TELEGRAM_BOT_TOKEN="التوكن_تبعك_هون"
python bot.py
```

**الطريقة الثانية - مباشرة بالكود:**
افتح `bot.py` وبدّل السطر:
```python
BOT_TOKEN = os.environ.get("TELEGRAM_BOT_TOKEN", "ضع_التوكن_هون")
```
حط توكنك مكان `ضع_التوكن_هون`

### 4. جرب البوت
افتح تيليغرام، دور على البوت باسم اليوزرنيم يلي اخترته، واضغط `/start`

## أوامر البوت

| الأمر | الوصف |
|---|---|
| `بيع 50000 سكر وشاي` | تسجيل عملية بيع |
| `مصروف 20000 فاتورة كهرباء` | تسجيل مصروف |
| `/balance` | رصيد اليوم |
| `/report` | تقرير الشهر الحالي |
| `/transactions` | آخر 10 عمليات |
| `/debt_owed اسم المبلغ سبب` | تسجيل دين إلك عند حدا |
| `/debt_mine اسم المبلغ سبب` | تسجيل دين عليك لحدا |
| `/debts` | عرض كل الديون المفتوحة |
| `/settle رقم_الدين` | تسديد دين معين |

## البيانات
كل شي بينخزن بملف `accounting.db` (قاعدة بيانات SQLite) بنفس المجلد — بسيط، محلي، بدون أي سيرفر خارجي أو اشتراك.

## الخطوة الجاية: تشغيله 24 ساعة مجانًا
البوت لازم يضل شغّال عالسيرفر حتى يرد على الرسائل بأي وقت. خيارات مجانية:
- **Railway.app** — خطة مجانية تكفي للبداية
- **Render.com** — نفس الفكرة، مجاني بحدود معينة
- تشغيله على جهاز كمبيوتر/رازبيري باي عندك يضل شغال بالبيت (لو عندك إنترنت مستقر)

## المرحلة الجاية: إضافة الذكاء الاصطناعي
لما يجهز عندك زبائن ومستعد تضيف:
1. تحويل الرسائل الصوتية لنص (Whisper)
2. فهم الجملة الحرة بدل الكلمات المفتاحية الثابتة (نموذج لغوي مجاني زي Gemini)
3. موقع ويب بسيط لعرض التقارير بيانيًا

قول لي وقتها ونبني هالجزء فوق نفس القاعدة الحالية بدون ما نغيّر شي.

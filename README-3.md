# بوت المحاسبة عبر تيليغرام

بوت مجاني بالكامل لتسجيل المبيعات والمصاريف والمشتريات والديون عبر تيليغرام — يصلح لأي محل أو نشاط تجاري.

## المميزات
- ✅ تسجيل بيع / مصروف / مشترى بجملة عربية طبيعية (بدون أوامر إنكليزية)
- ✅ ربط اسم زبون اختياري بأي عملية بيع
- ✅ تتبع الديون (لك / عليك) مع تسديد بضغطة زر
- ✅ تقارير حسب الفترة: يومي، أسبوعي، شهري، سنوي
- ✅ عرض تفاصيل كل قسم (مبيعات/مصاريف/مشتريات) مع حذف أي عملية بضغطة زر
- ✅ كل شي بأزرار تفاعلية (Inline Buttons) بدون كتابة أوامر معقدة

## طريقة الاستخدام (أمثلة)

| الكتابة | النتيجة |
|---|---|
| `بيع سكر كيلو 50000` | تسجيل بيع |
| `بيع سكر 50000 زبون أحمد` | تسجيل بيع مرتبط باسم الزبون |
| `مصروف فاتورة كهرباء 20000` | تسجيل مصروف |
| `مشترى بضاعة من المورد 100000` | تسجيل مشترى |
| `دين لسامر 5000` | عليك دين لسامر |
| `دين من أحمد 100000` | إلك دين عند أحمد |
| `تسديد سامر` | تسديد آخر دين مفتوح باسمه |

**الأزرار تحت الشاشة:** بيع، مصروف، مشترى، التقارير، آخر العمليات، الديون — كل زر بيفتحلك قوائم وخيارات تفاعلية.

## خطوات التشغيل

### 1. إنشاء البوت والحصول على التوكن
1. افتح تيليغرام وابحث عن `@BotFather`
2. أرسل له `/newbot` واتبع التعليمات
3. احفظ التوكن يلي رح يعطيك ياه

### 2. تثبيت المتطلبات
```bash
pip install -r requirements.txt --break-system-packages
```

### 3. تشغيل البوت
```bash
export TELEGRAM_BOT_TOKEN="التوكن_تبعك_هون"
python bot.py
```

## البيانات
كل شي بينخزن بملف `accounting.db` (SQLite) بنفس المجلد — محلي بالكامل، بدون أي سيرفر خارجي.

ارفع المشروع على **Railway.app** أو **Render.com** (خطط مجانية) وربطه بمتغير `TELEGRAM_BOT_TOKEN`.

## تفعيل الذكاء الاصطناعي (فهم الصوت والصياغات الحرة)

البوت هلق بيدعم استقبال رسائل صوتية وفهم صياغات عربية غير معتادة، عن طريق **Gemini من Google (مجاني بحدود سخية جدًا)**.

### الحصول على مفتاح مجاني
1. من متصفح التلفون/اللابتوب روح لـ **aistudio.google.com**
2. سجل دخول بحساب Google عادي (Gmail)
3. اضغط **"Get API key"** ثم **"Create API key"**
4. انسخ المفتاح (يبدأ بـ `AIza...`)

### إضافته لـ Railway
1. روح لمشروعك بـ Railway → تبويب **Variables**
2. أضف متغير جديد:
   - **Name:** `GEMINI_API_KEY`
   - **Value:** المفتاح يلي نسخته
3. احفظ — البوت رح يعيد التشغيل ويصير الذكاء الاصطناعي مفعّل تلقائيًا

### كيف بيشتغل
- الجمل الواضحة (`بيع سكر 50000`) تتعالج فورًا بدون AI — مجاني ومباشر
- الجمل الغريبة أو الصياغات غير المتوقعة تتحول تلقائيًا للذكاء الاصطناعي
- أي **رسالة صوتية** ترسلها للبوت تتفهم تلقائيًا بالكامل عبر الذكاء الاصطناعي

الخطة المجانية من Gemini كافية جدًا لمئات الرسائل يوميًا بدون أي تكلفة.
